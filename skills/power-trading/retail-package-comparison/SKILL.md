# 零售套餐比价与固定价保本点

## 适用场景
- 同一期间、同一负荷下，比较固定价、分时价和市场联动价三种套餐的电能量费用。
- 算固定价套餐的保本现货价、价格安全垫和度电净利。
- 比价的公式和保本点的成本参数是行业经验口径，不是官方规定（〈零售套餐的形式与比价风险口径〉〈固定价套餐保本点的测算口径〉），回答时要说明。

## 需要的输入
- 同一期间各时段的用电量，写明单位和时段名。
- 固定价套餐的固定价；分时价套餐各时段的电价。
- 市场联动套餐：传导系数、加价、上限、下限，以及基准情景下各时段的市场价（〈零售套餐的形式与比价风险口径〉）。
- 保本点：零售价、中长期比例、中长期价、现货价、年电量；有度电偏差成本、度电运营成本和履约保障的资金成本时一并给出（〈固定价套餐保本点的测算口径〉）。

## 步骤
1. 先讲口径：运行 `bailu handbook`，参数写「零售套餐的形式与比价风险口径」。比价只比电能量；输配电价、系统运行费、基金附加和基本电费各种套餐都要交，须同口径加回（〈工商业用户到户电价的五个组成部分〉）。
2. 算比价：运行 `bailu calc retail_compare --message "<用户原话>"`。数字由程序从用户的话里读取，一次给齐三个套餐的数字。命令输出给出各套餐的电能量费用、度电均价、市场价下浮和上浮两成的情景，以及联动与固定价持平的市场价变动。输出以「还缺」开头时，把缺的项目和给出的例句原样告诉用户。
3. 算保本点：运行 `bailu calc fixed_break_even --message "<用户原话>"`。命令输出给出度电净利、净利、保本现货价和价格安全垫。
4. 用户问合同该写什么：运行 `bailu handbook`，参数写「零售合同怎样签订与必备内容」「售电公司的批发零售结算」。问本省的零售规定：运行 `bailu docs <政策文件夹> "<省份名> <事项名>"`（第一个参数是用户放本省文件的文件夹或文件，最后一个是问题）。

## 输出格式
- 第一句：结论（哪个套餐便宜、联动的临界点，或保本现货价和安全垫；还缺数字时说还缺什么）。
- 第二句：提醒公共科目要同口径加回，套餐价格不等于到户价。
- 第三句：说明公式和成本参数是测算口径，以零售合同为准。
- 命令输出的表格原样放进回答，不要改动其中的数字。

## 常见错误与提醒
- 每个数字前面写明它是什么，电量写单位；没写单位的电量按万千瓦时、电价按元/千瓦时读，结果里会注明。
- 市场联动价按市场价乘传导系数再加价，可设上下限；要看传导系数、加价、上限、下限四个参数。情景价格由用户给，你不预测价格（〈零售套餐的形式与比价风险口径〉）。
- 保本现货价高出当前现货价的幅度是价格安全垫，没有统一的合理值；「零售价减批发价」只是毛价差（〈固定价套餐保本点的测算口径〉）。
- 零售合同以月为最小单位签订，应包括电量及分月计划、费用结算、违约责任、电力用户偏差电量处理方式等（〈零售合同怎样签订与必备内容〉）。
- 售电公司管理办法 2021 年版的有效期在 2026 年 11 月届满，引用前看〈售电公司管理办法的时效〉。
