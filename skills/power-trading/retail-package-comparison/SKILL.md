# 零售套餐比价与固定价保本点

1. 确认同一账期和负荷的分时电量、固定价、分时单价、联动传导系数、加价、市场情景和上下限约定。统一单位。按〈零售套餐的形式与比价风险口径〉核对合同公式。
2. 用工作表或 Python 标准库 `decimal.Decimal` 逐时段算电量 × 单价，再加总并除以总量得到均价。联动示例为（市场价 × 传导系数 + 加价）按合同上下限截断。用用户指定情景复算，需要临界点时按相同负荷求联动总费与固定总费相等的市场价。存在限价平台或无交点时说明。
3. 保本测算确认零售价、中长期比例、中长期价、现货价、电量及度电偏差、运营和资金成本。加权批发价 = 中长期比例 × 中长期价 +（1 − 中长期比例）× 现货价。度电净利 = 零售价 − 加权批发价 − 度电成本，净利 = 度电净利 × 电量。保本时将度电净利设为零反解现货价。中长期比例为 100% 时没有该模型下的现货保本点。只有对照现货价大于零时才给比例安全垫。
4. 公共费用按同口径另列，见〈工商业用户到户电价的五个组成部分〉。保本假设见〈固定价套餐保本点的测算口径〉。涉及零售合同或省级规定，按 policy-lookup 核实原文和日期。

先给金额、差异、情景条件和临界点，再附价格及电量明细。
