# 电费账单核对

## 适用场景
- 用户给出账单（附了文件或列出科目），问账单对不对、某一项为什么这么收。
- 核对的是科目是否齐全、计费口径是否符合规定。能复算的是分时电费、基本电费和功率因数调整电费，其余科目不要自己乘加。

## 需要的输入
- 省份、账单月份、代理购电还是直接入市、电压等级、单一制还是两部制、基本电费按容量还是按合同最大需量。
- 各科目的电量、计费基础、单价、金额。
- 账单附成了 PDF 或 Word：运行 `bailu docs <账单文件> "基本电费 需量"`（第一个参数是账单文件的路径）取账单原文；提示无法读取的，请用户把各科目的数字打出来。

## 步骤
1. 先看科目是否齐全。直接入市的用户侧结算账单包括电能量费用、输配电价、线损电费、系统运行费、政府性基金及附加（〈结算账单包含的费用〉）；代理购电用户电价由代理购电价格、输配电价、政府性基金及附加组成（〈代理购电用户电价的构成〉）。
2. 只查用户问到或有疑问的科目：运行 `bailu handbook`，参数写下表的主题名，一次最多两个；按下表逐项核对。
3. 复算分时电费：请用户按「时段名 用电量 电价」给出各时段数字，运行 `bailu calc tariff --message "<用户原话>"`；把合计与账单上的电能量电费比较，只说一致还是不一致，不算差额。
4. 复算基本电费：用户给出变压器容量、容量电价、需量电价、合同最大需量和实际最大需量时，运行 `bailu calc basic_charge --message "<用户原话>"`（容量电价和需量电价没给时，可用 `bailu tariff` 查出本省的表告诉用户）。功率因数调整电费：用户给出有功电量、无功电量、功率因数标准、调整比例和调整基数时，运行 `bailu calc power_factor --message "<用户原话>"`。两种都把结果与账单比较，只说一致还是不一致。
5. 有疑问时告诉用户怎么办：结算依据或电费账单发布后，可在 15 个工作日内分别向电力交易机构、电网企业提出结算问询（〈结算问询的提出与处理〉）。

| 科目 | 核对什么 | 手册主题 |
|---|---|---|
| 输配电价 | 现行用 1077号附件，不再用 526号附件；电压等级档位、单一制或两部制与用户是否一致；单价用 `bailu tariff` 查出本省的表再比（参数写省份、单一制或两部制、电压等级和要查的电价） | 〈输配电价的监管周期与核定办法〉〈输配电价按电压等级分档的结构〉 |
| 线损 | 上网环节线损费用在输配电价外单列，线损率写在电价表表注 | 〈上网环节线损费用的计算与列支〉 |
| 基本电费 | 按容量或按合同最大需量，同一计费周期只能选一种；实际最大需量超过合同确定值 105% 的部分加一倍，核定值低于变压器容量和高压电动机容量总和 40% 的按 40% 核定；新装、增容、终止当月按日折算 | 〈基本电费按容量还是按需量计收〉〈合同最大需量超105%的加收规则〉〈容需量电费的按日折算规则〉 |
| 功率因数调整 | 三档标准是否用对；表计不在产权分界点时损耗电量要计入 | 〈功率因数标准的三档适用范围〉〈表计不在产权分界点时损耗归谁〉 |
| 系统运行费 | 包括辅助服务费用、抽水蓄能容量电费、煤电容量电费等；煤电容量电费每月由工商业用户按当月用电量比例分摊 | 〈系统运行费用的来源与列支变化〉〈煤电容量电费的计算与分摊〉 |
| 基金附加 | 国家设立的是四项；城市公用事业附加已取消；现行标准分省规定 | 〈政府性基金及附加包含哪些项目〉 |
| 转供电 | 不得在水电气暖费用中加收其他费用 | 〈转供电不得在电费中加收费用〉 |

## 输出格式
- 第一句：结论（科目是否齐全，哪几项口径对得上，哪几项对不上或无法核对）。
- 逐项写核对结果，每项一句，后面写依据（文件名和条款编号，照命令结果的写法）。
- 最后列出要查本省文件的科目和下一步建议。命令输出的表格原样放进回答，不要改动其中的数字。

## 常见错误与提醒
- 本省的输配电价（电量电价、需量电价、容量电价）和上网环节线损率用 `bailu tariff` 查；基金附加标准不在手册里：运行 `bailu docs <政策文件夹> "<省份名> <科目名>"`（第一个参数是用户放本省文件的文件夹或文件，最后一个是问题）；查不到就请用户放本省文件。
- 功率因数调整的比例表和计费基数不在手册里，现行办法是 1983 年的《功率因数调整电费办法》（〈功率因数调整电费的现行依据〉）；比例和基数用 `bailu docs <政策文件夹> "<省份名> <科目名>"` 查本省文件。
- 1077号没有重申需量电价的九折条件，是否延续查本省文件（〈两部制需量电价的九折条件〉）。
- 计费方式和核定值的变更时限以本省细则为准（〈基本电费计费方式的变更时限〉）。
- 账单每月第 10 个工作日前发行，具体以所在省公布的结算时序为准（〈月度结算的时间节点〉）；追退补的追溯期原则上不超过 12 个月（〈追退补和清算怎样进行〉）。
