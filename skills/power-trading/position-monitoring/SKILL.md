# 交易风险快照与情景

1. 明确检查时点、交割窗口、地区、节点、主体、买卖方向、账本和需监控的阈值。从数据清单或源文件确认截至该时点的快照和时效。只按已生效规则或用户确认的阈值判断，缺阈值时可以给指标。
2. 从成交、计量和预测对齐时段，区分已成交、申报草稿、实测和预测。敞口以净暴露电量为基础，注明哪部分用预测、是否含偏差考核。历史尾部和数据质量用 `price-risk-check`，头寸口径用 `trading-review`，预测区间用 `market-forecasting`。
3. 用同一套结算口径比较对照与低、中、高价格／负荷／供给情景，逐项计算量、价、考核和费用的变化。条件相关时并列联合压力情景，说明假设来源。汇总前确保金额、单位、时段、区域与买卖方向一致。保留缺价的电量，并标出尚无法计算的金额。
4. 交付一份指定时点风险快照。每项列阈值、实测或情景结果、比较方向、状态（触发、未触发或待补证）、数据时效与证据。记录需要关注的时段和要确认的动作。阈值前后、数据迟到或快照修订时，保留两次结果及受影响的指标。

每次运行都以项目文件或经授权取得的公开快照为准。明确起止时刻，让日报能够独立复算。
