# 交易复盘与持仓

1. 读取 trading-ledger 的成交、申报和计量文件。确认起止日、已计量日是否齐全、每天实时加权价。成交跨日时按合同曲线分配，曲线不可用时仅在用户认可日均分配口径后使用平均值。售电头寸取负数。
2. 将已确认的日前成交计入日前头寸。同一天同方向有已确认的日前成交时，对应原申报仅作记录，避免双计。草稿或非日前申报不作为已成交电量。注明用申报数据作为近似的项。
3. 在 Python 标准库 `decimal.Decimal` 或工作表中逐日计算。这里的日前头寸是独立于中长期头寸的增量，若用户提供的是日前总量，先转换口径：
   - 偏差量 = 实际计量 − 中长期头寸 − 日前增量头寸。
   - 电能量费 = 各中长期合约的分摊电量 × 约定价之和 + 已确认日前增量价款 + 偏差量 × 实时价。
   - 全实时对照 = 实际计量 × 实时价。各头寸的套保贡献 = 该头寸量 × 实时价 − 对应价款。对照减电能量费应等于两类头寸贡献之和。
4. 持仓覆盖率、日前占比和偏差率按各自总量除以实际计量总量，基数为零时标作不适用。缺少实时价的日保留电量与原因，对照、金额及归因只汇总共同具备价格的日期。实际账单另有费用或结算口径时，按当期规则核算后单列。
5. 先报期间结论，再给逐日表、持仓覆盖、偏差、资金归因、依据和缺项。政策背景查〈现货市场与中长期市场的衔接〉、〈日清月结、结算依据与结算账单〉。
