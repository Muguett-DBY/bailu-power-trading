# 月度价格分析报告

1. 要有用户提供的交易平台 CSV 或 Excel、工作表、时区、时间粒度、价格列和实际单位。先按 price-risk-check 检查时间、重复、缺时段和数值。用户没给月份时，说明采用的最后一个完整月；只有不完整月时明确说出覆盖范围，再按需要分析。
2. 用宿主的数据工具、Python 或工作表公式从明确列按日期筛选。可参考 `analysis/tables.py` 的读取方式，统计前核对原始列和单位。输出总行数、有效数、按月及当月的简单均价、最低价和最高价时间；有对齐电量时另外算电量加权均价。日前与实时差额只使用两列都有有效值的时点。
3. 需要按时段排名时，按同一地方时刻或用户指定峰平谷分组，列各组样本数和均价，再比较。月间比较写明每月数据覆盖。全表统计、缺失月份和同比环比有各自的时间条件。
4. 交付标题、文件与口径、当月概览、极值及时间、时段特点和月间比较。注明价差指全样本最大值减最小值，还是各时段均价的最大值减最小值。手册〈常用分析指标〉提供行业口径，图表用 data-visualization。

留存计算用的字段和筛选条件，报告数字来自实际计算。仅描述已有数据。
