# 用户侧储能与负荷平移测算

1. 确认地区、账期、直接入市或代理购电、可用充放电时段和实际价格。用 policy-lookup 查现行分时政策，阅读手册〈直接入市主体的分时电价〉、〈负荷平移与蓄冷蓄热的收益口径〉和〈储能削峰降低基本电费的口径〉。
2. 套利用 `decimal.Decimal` 或工作表按用户口径计算。放电量 = 额定容量 × 允许放电深度，已知单次可用电量时直接采用。购电量 = 放电量 ÷ 往返效率，单循环毛收益 = 放电量 × 放电价 − 购电量 × 充电价。核对充放电功率、时窗与可实现电量。按可运行天数和每日循环次数年化，单列运维、折旧等项目。给了投资和循环寿命时，注明折旧和现金流采用哪种口径，再算投资回收期。
3. 负荷平移无损耗时，日节省 = 转移电量 ×（源时段电价 − 目标时段电价）。蓄冷、蓄热或储能有损耗时，按实际效率把目标时段购入的电量倒算出来，分别计入两端辅助电耗并检查容量限制。
4. 基本电费节省按每月峰值，结合 tou-tariff-bill 核定申报、超需量与折算，分别复算有无储能两种账单。容量方式需要确认是否有实际减容。如需需量单价，按省份、账期和电压档查 `knowledge/data/tariffs.txt` 及表注。运行价差与基本电费分别列出。
5. 需要历史日前价的完全预见上界，用 `analysis/backtest.py` 的储能选项，参数见 `analysis/README.md`。给出各输入出处、运行条件、计算细目与缺项。上界和情景结果用于测算参考。
