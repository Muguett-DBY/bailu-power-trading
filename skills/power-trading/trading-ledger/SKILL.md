# 交易台账与档案

## 适用场景
- 用户做了一笔中长期交易，签了合约，或拿到了成交结果，要记下来。
- 用户每天或每月拿到实际用电量，要记录。
- 用户要查某段时间签了哪些合约、申报了多少、用了多少电。

## 需要的输入
- 成交：成交日期、市场（年度、月度、月内、日前、挂牌、双边……）、方向（购电或售电）、对手方、电量（兆瓦时）、价格（元/兆瓦时）、合约覆盖的起止日期。
- 计量：日期、实际用电量（兆瓦时），有当日实时加权均价时一起给（元/兆瓦时）。
- 申报：见 declaration-checklist 技能。

## 步骤
1. 记成交：`bailu ledger add 成交 日期=<成交日期> 市场=<市场> 方向=<购电/售电> 对手方=<名称> 电量=<兆瓦时> 价格=<元/兆瓦时> 开始=<起始日> 结束=<截止日> 备注="<一句话>"`。跨多日的合约一定要写开始和结束；不写时按成交当日交付。
2. 记用电：`bailu ledger add 计量 日期=<日期> 电量=<兆瓦时> 实时均价=<元/兆瓦时>`。实时均价可以从电价表统计出来（`bailu table "<某天>实时加权均价是多少" <电价表文件>`），没有就先不写。
3. 查询：`bailu ledger list` 看全部；`bailu ledger list 成交 from=2026-11-01 to=2026-11-30` 只看一段时间的合约。
4. 用户问「我们签了多少」「某月的合约均价是多少」这类问题时，先 `bailu ledger list`，再按需要交给 trading-review 技能（`bailu review`），不要自己把台账里的数字加起来。

## 输出格式
- 记录后把命令输出的那一行原样告诉用户（记入了哪个文件、第几条、记录了哪些字段）。
- 查询时把命令输出的表格原样放进回答，再用一句话说明这段时间有几笔、方向如何。

## 常见错误与提醒
- 字段缺了、日期不是「2026-12-01」这样的写法、只写了开始没写结束，命令都会指出是哪一项，照原样告诉用户。
- 电量单位是兆瓦时、价格是元/兆瓦时；带单位写也可以（「1045万千瓦时」「0.43元/千瓦时」），程序会换算。没有单位的数字按这两个单位算，所以先和用户确认单位。
- 方向写「购电」或「售电」；售出的合约在复盘里按负数计。
- 台账在项目的 `bailu-workspace/ledger/` 下，是可以用 Excel 打开的 CSV。只追加，不改写，不删除已有的行；记错了告诉用户由其处理。
- 台账是用户的数据，不要放进报告或发给第三方。
- 合约的结算方式（差价合约、结算参考点）见〈差价合约与结算参考点〉；每月的结算依据和账单见〈日清月结、结算依据与结算账单〉；核对账单需要哪些数据见〈结算基础数据包含哪些〉。
