# 电力时序预测与回测

1. 确认对象、地区、节点或资产、时间粒度、截止时刻和预测范围。定义价差方向、出力与电量单位、供需状态。日前与实时价要同节点同交割时段配对，价差默认用日前减实时；净负荷默认用同期负荷减新能源出力。跨市场价差单独说明两端交割、网损和费用口径。
2. 按 `market-data-intake` 整理快照。保留历史实测、当时预测和事后修订各自的版本。天气预报用当时已发布版本；实测气象用于事后解释，或在确有当时可见记录时作相应特征。供给侧确认已知检修、装机或可用容量的定义，负荷侧确认计量边界以及时段长度。
3. 使用框架的 `analysis/forecasts.py` 做滚动回测，用 `--column` 选「日前」「实时」「价差」「负荷」「风电」「光伏」「新能源」「可用供应」「净负荷」，用 `--horizon` 指定时段数，可加 `--out` 生成副本。依赖与运行命令见框架的 `analysis/README.md`。在每个起点只使用当时可用的观测和版本，按交割时段对齐真实值。用同一组评估时段比较候选基线，记录缺失和样本量。
4. 交付预测目标、交割区间、原数据版本、基线、样本量、MAE 或 RMSE 及区间实际覆盖率。区间证据不足时明确缺项。气象、供需和限电解释用带出处的情景假设，并说明它们是否参与计算。历史回测及方案比较按 `trading-workflow`，敞口和风险阈值按 `position-monitoring`。

滚动起点的训练集在该起点之前，后续观测仅作验收。[时序交叉验证方法](https://otexts.com/fpp3/tscv.html)
