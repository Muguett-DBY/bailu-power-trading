# 概念与机制解释

## 适用场景
- 用户问概念、术语、机制的含义，或两个概念的区别。
- 用户只问「怎么算」而没有给数字：先解释算法，再告诉用户给齐哪些数字就能直接算。

## 需要的输入
- 概念名：用用户的话里的专有名词。
- 用户问的角度：是什么、有什么区别、为什么、和什么有关。不涉及省级规定时不必追问省份。

## 步骤
1. 运行 `bailu handbook`，参数写概念名，可以带上用户问的角度，如「节点边际电价 分区边际电价 区别」。一次最多写两个概念名。
2. 核对结果：
   - 是「没有找到相关内容」：把概念名换个说法再查一次；还没有就直说手册里没有这个概念，不要凭印象解释。
   - 有结果：每段以【内置手册·主题名】开头，内容只取自这些段落。
3. 有结果时按下面的顺序写：
   - 一句话定义。
   - 怎么运作或为什么这样设计，分两到三点，每点一句。
   - 和哪些概念有关、容易混在哪里；只写本次结果里有的相关内容。
   - 依据：文件名和条款编号，照命令结果的写法。
4. 用户问的是两个概念的区别，而本次结果只有其中一个：换另一个概念名再运行一次 `bailu handbook`；还没有就说明手册缺这部分。
5. 问题落到本省怎么规定（如本省用哪种定价机制、统一结算点电价怎样加权、限价多少）：属于省级规定，改用 `bailu docs`，参数带上省份名，按 policy-lookup 技能核对。
6. 用户只问怎么算、没有给数字：先运行对应的 `bailu calc`，命令会返回还缺哪些数字和一句例句；再用 `bailu handbook` 取算法原文。回答时说明算法，告诉用户给齐哪些数字就能直接算，例句照命令返回的写。
7. 常见概念的首查主题（参数可以直接用主题名）：
   - 节点边际电价 → 「节点边际电价、分区边际电价、系统边际电价」；相关「统一结算点电价」「安全校核、市场出清与阻塞」。
   - 差价合约 → 「差价合约与结算参考点」；相关「两种结算方式」。
   - 日清月结 → 「日清月结、结算依据与结算账单」；相关「现货未连续运行时的结算周期」「月度结算的时间节点」。
   - 偏差、考核 → 「偏差电量」；限价 → 「市场限价」。

## 输出格式
- 先给一句话定义，再分点说明，每点一句；结尾一句写依据。
- 用户只问怎么算：说明算法和公式，最后告诉用户给齐哪些数字就能直接算。

## 常见错误与提醒
- 数字、日期、条款编号只照命令结果写。不举带数字的例子，命令结果里没有的数字不要写。
- 标【口径】的内容（如〈常用分析指标〉、〈统一结算点电价〉里的口径段）是行业常用说法，不是官方定义，要说明。
- 省级的具体数字（限价、时刻、考核比例）不在手册里，不要凭记忆写。
- 不预测价格，不给交易建议。
