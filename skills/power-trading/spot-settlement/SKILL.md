# 现货结算电费计算与解读

1. 确认交易地区、主体、账期和结算方式。在 `knowledge/handbook/` 查〈两种结算方式〉、〈用户侧电能量电费：方式二〉和〈统一结算点电价〉。涉及实际账期按 policy-lookup 核对当时规则。发电侧、仅实时市场或所用结算方式不同，按原文另算。
2. 列出同一结算时间粒度的合约电量和价格、日前出清量和价格、实际电量、实时价、合约结算参考点价格。明确无合约时合约量为零。价格单位统一用元/MWh，电量统一用 MWh。缺关键项时先问，用已确定的输入继续核算其他项。
3. 方式二用 Python 标准库 `decimal.Decimal` 或工作表里的公式计算。对每个结算段分别算：
   - 合约项 = 合约电量 ×（合约价 + 日前价 − 参考点价）。
   - 日前项 =（日前出清量 − 合约电量）× 日前价。
   - 实时项 =（实际电量 − 日前出清量）× 实时价。
   - 电能量费为三项合计。全部按实时价买的对照 = 实际电量 × 实时价。对照减电能量费是套保效果，正值为节省。
4. 本省另有偏差考核时，用 deviation-assessment 的规则与输入单列考核费。逐段结算再汇总。月累计量只适合搭配同口径的加权价做估算，说明与逐结算段实算的差异。

先列电能量费和应付合计，给出金额表、偏差电量和套保对照，注明每个数据的来源。输配、线损、系统运行费和基金附加按〈结算账单包含的费用〉另列。追问只更新用户修正的字段，沿用已确认的口径。
