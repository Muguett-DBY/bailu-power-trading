# 数据体检与风险监控

## 适用场景
- 用户从交易平台导出了一份电价表或负荷表，要分析、画图、写报告，或问「这份数据能不能用」。
- 用户要风险指标：价格波动、极端价格、没有避险的电量最坏要多花多少。
- 用户问某个月或某个时段的均价、最高最低价。

## 需要的输入
- 电价表或负荷表文件（CSV 或 Excel）的路径，表里要有时间列和价格列或负荷列。
- 算风险时：从哪一方看（购电或售电）、置信度（默认 95%）、没有避险的电量（兆瓦时）、基准价（元/兆瓦时，不给时用这段历史的均价）。省份名（用来查限价规则）。

## 步骤
1. 先运行 `bailu check <文件>`。有「错误」（读不出数字、重复、乱序、缺时段）时，逐条告诉用户，请其先处理或确认；「提醒」（缺值、负电价、持续持平、离群值）说明可能的原因，请用户对照来源确认。**有错误没有得到处理前，不要拿这份数据下结论。**
2. 用户问统计：运行 `bailu table "<问题>" <文件>`（问法示例：「哪个月实时均价最高」「比较8月和7月的日前均价」「各时段平均负荷」）。
3. 用户要风险指标：运行 `bailu risk <文件> --side buy --confidence 95 --mwh <电量>`（售电方用 `--side sell`，看的是低价风险）。
4. 用大白话解释每个指标，数字照命令输出：
   - 分位数、VaR：95% 的时段价格不高于这个数（售电方：不低于这个数）。
   - CVaR：最贵的 5% 时段的平均价格。
   - 波动：相邻时段价格变动的标准差。
   - 尾部成本：按给的电量在各时段平均分摊，最贵的 5% 时段比按均价多花多少。
   - 回撤：以基准价计，逐时段累计的节省从最高点回落的最大幅度。
5. 用户问本省的价格上下限是多少：用 `bailu handbook` 带省份名查（如〈山东省现货市场的限价与二级限价〉〈市场限价〉），并提醒以现行文件为准。

## 输出格式
- 第一句：结论（数据有没有问题；风险是大是小，用具体数字说，如「95% 的时段价格不高于 500 元/兆瓦时，最贵的 5% 时段均价 812 元/兆瓦时」）。
- 数据问题逐条列出；没有问题就说明检查过哪些项。
- 风险指标的表格或数字，照命令输出。
- 最后一句：这些是对过去一段时间的描述，不是对未来的预测。

## 常见错误与提醒
- 不预测价格，不给「该不该买」「该不该套保」的结论；把尾部成本、覆盖率这类数字算清楚，由用户决定。
- 没有给 `--mwh` 时回撤的单位是「元/兆瓦时」（每兆瓦时的累计节省），给了才是元，解释时不要混。
- 置信度写在 0 到 100 之间；样本只有几天时，尾部指标只能作参考，要告诉用户。
- 表里的单位（元/兆瓦时还是元/千瓦时）程序按列名和数值大小判断，回答里写明用的是哪个单位。
- 市场风险的种类见〈风险的类型〉；常用的统计指标口径见〈常用分析指标〉。
