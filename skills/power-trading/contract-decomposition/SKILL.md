# 中长期合约分解、电费与套保

1. 取合约电量、合约价和用户要拆分的日期、月份或时段。给了权重时核对其数量、非负性和权重和。同类数据统一用 MWh 与元/MWh。
2. 用工作表公式或 Python 标准库 `decimal.Decimal` 分解：某份电量 = 总量 × 本份权重 ÷ 权重和。等额拆分给每份权重 1。按交付要求的精度显示，账表需精确回合计时按确认的尾差规则分配并列出调整。
3. 合约电费 = 合约量 × 合约价。只有合约部分与现货比较时，差额 = 合约量 ×（对照现货价 − 合约价），正数表示合约更省。用户问含日前及实时差额的完整套保效果，按 spot-settlement 计算。
4. 正式的合同曲线按合同、细则和交易公告。用 policy-lookup 查「合约 分解 曲线」，参考手册〈合同曲线与典型负荷曲线〉、〈差价合约与结算参考点〉。

开头给结果。附分解份数、权重、各份电量与总量核对，或列两种价格下的电费和差额。区分合同分解规则与算术分摊。
