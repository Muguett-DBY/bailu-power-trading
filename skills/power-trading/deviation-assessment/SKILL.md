# 偏差电量、偏差率与考核费用

1. 确认基数是日前出清量、申报量还是中长期合约量，并统一单位。日前出清与实际之间的电费按 spot-settlement 的实时项复算。涉及代理购电，读手册〈代理购电偏差电量的结算价格〉。
2. 用 Python 标准库 `decimal.Decimal` 或工作表公式计算偏差电量 = 实际量 − 约定基准量。基数大于零时，偏差率 = 偏差电量 ÷ 基数。基数为零时可报偏差电量，偏差率列为不适用。
3. 考核先核对方向（双向或单向）、免考比例、考核比例、考核电价及分段规定。按 policy-lookup 阅读适用省份和账期的原文。省级规则采用双向对称的单一免考带时，超限电量 = max(0, |偏差电量| − 基数 × 免考比例)，费用 = 超限电量 × 考核电价 × 考核比例。分段、单向或特殊考核按原文重算。有缺项时先交付能核实的偏差量和偏差率。
4. 输出正负号、各项用量和单位、结果与来源。过往口径和本次适用文件不同，写出差异。涉及分摊时查手册〈补偿考核费用的分摊与披露〉。

费率和价格优先用本项目证据和适用原文，计算过程留在工作底稿。
