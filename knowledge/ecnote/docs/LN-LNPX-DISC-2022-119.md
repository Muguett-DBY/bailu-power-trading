（一）二、重点任务[#U0003](https://ecnote.alioc17.cn/doc/LN-LNPX-DISC-2022-119#U0003 "条文锚点 #U0003")

(一)融入多层次统一电力市场体系.积极融入国家电力市场建设 。鼓励市场主体主动参与建立跨省跨区市场交易机制，在全国电力交易中心组建过程中发挥积极作用?争取参与各级电力市场管理委员会。完善辽宁电力市场管理委员会制度，形成行业自律规范，研究电力市场化交易中出现的重大问题，提出解决措施建议?监督市场运营和交易规则执行情况。. 稳步推进省内电力市场建设。充分发挥辽宁电力交易中心作用?协调国家、区域交易机构，配合建立跨省跨区交易机制，明确各级市场协同机制和工作界面。提高省内电力资源配置效率?保障电力平衡。. 各层次电力市场协同运行 。鼓励市场主体参与各层次市场交易，促进市场融合。对接国家、区域各级市场运营机构，建立信息报送和业务协调机制，强化省问、省内市场交易信息互通共享。支持辽宁电力交易中心参与电力一- 4 一一交易中心联营体，加强与各级市场运营机构业务协同运. 主动参与跨省跨区市场间开放合作 。 积极推动市场主体参与跨省跨区交易，支持开展跨省跨区输电权交易，市场化灵活调剂余缺，改善省内用电价格结构，提升省问输电通道利用水平 。 鼓励市场主体在国家有关政策、规则框架内直接参与省间交易 。 推动将国家送电计划、政府送电协议转化为政府授权的中长期合同 。 完善政策环境，推动省内市场与跨省跨区市场在经济责任、价格形成机制等方面实现动态衔接 。

（二）二、重点任务[#U0004](https://ecnote.alioc17.cn/doc/LN-LNPX-DISC-2022-119#U0004 "条文锚点 #U0004")

(二)完善统一电力市场体系功能. 深化省内电力中长期交易市场建设 。 保持中长期交易电量合理比例，发挥中长期市场在平衡长期供需、稳定市场预期的基础作用 。 缩短交易周期，提升交易频次，丰富交易品种，逐步实现中长期交易连续开市 。 鼓励开展年以上期限的中长期交易 。 完善中长期合同市场化调整机制，为市场主体提供合同偏差调整手段 。 规范交易合同签订，实现全品类交易合同签订、履约、结算全程电子化线上开展。规范开展中长期分时段交易，完善价格传导机制，拉大峰谷价差，引导用户削峰填谷，实现与现货市场的有效衔接。. 积极稳妥推进电力现货市场建设 。 落实国家电力现货市场第二批试点工作部署，按照"模拟试运行、结算试运行、正式运行"，分步实施电力现货市场建设 。 建设电力现货技术支持系统，实现与交易平台、营销结算等数据互通。完善市场主体计量方式，使市场主体具备参与现货市场条件 。 发挥现货市场发现价格作用，准确反映电能量时间和空间价值 。 有序推动各类优先发电主体、用户侧共同参与现货市场。实现现货交易与放开优先发用电计划、中长期交易的衔接 。 建立合理的市场损益和费用疏导机制。建立超额获利回收与考核机制 。. 完善辅助服务市场建设 。 在辅助服务市场中?建立适合灵活调节性资源的交易品种 。 建立省内调频辅助服务市场，与现货电能量市场同时启动、独立运行、有序衔接、分开结算 。 设计用户可调节负荷参与辅助服务交易品种?推动源网荷储一体化建设和多能互补协调运营?完善成本分摊和收益共享机制 。 编制辽宁省电力市场运营基本规则及现货电能量交易、辅助服务市场、中长期交易、结算、零售管理和计量管理六个细则?实现电力中长期、现货、辅助服务市场的有效衔接 。. 培育多元竞争的市场主体 。 进一步放开发用电计划，推动新能源、核电等优先发电主体参与市场。逐步将省内优先发电、优先购电计划转化为政府授权的中长期合同。编制售电公司管理实施细则，明确售电公司准入标准和条件 。 畅通准入渠道?依法引导社会资本参与售电业务 。 发挥电网企业普遍服务和保底作用，引导售电公司健康发展 。 加强零售市场管理，鼓励售电公司创新商业模式，提供综合能源管理、负荷集成等增值服务 。 拓展交易品种?引导储能、虚拟电厂等新型市场主体参与市场交易?充分激发和释放用户侧灵活调节能力 。

（三）二、重点任务[#U0005](https://ecnote.alioc17.cn/doc/LN-LNPX-DISC-2022-119#U0005 "条文锚点 #U0005")

(三)健全统一电力市场交易机制. 规范市场交易规则和技术标准 。 完善辽宁省电力市场交易规则体系 ? 规范市场主体管理、各类交易组织和运行 。 建立"一口对外"的工作机制?辽宁电力交易平台作为统一电力交易平台，加强平台建设和功能优化升级?统筹支撑电力中长期、现货、辅助服务市场 。 辽宁电力交易中心要与国家、区域电力交易中心及外省交易中心在技术和数据标准方面有效衔接?按照国家统一技术标准开展建设和运营 。 组织辽宁电力交易中心依照基本交易规则制定交易细则。. 完善电力价格形成机制。全面落实燃煤发电上网电价改革?完善电价传导机制 。 完善电力市场价格规则，发挥电力市场价格引导作用，提高省内电源顶尖峰发电能力、新能源发电消纳能力，有效平衡电力供需。逐步缩小电网企业代理购电规模，推动全部工商业用户进入市场 。确保居民、农业、公益性事业等优先购电用户电量全部由清洁能源、省外来电等执行保量保价的优先发电电量供给 。 优先购电用户电价执行现行目录销售电价政策，实现价格相对稳定 。 鼓励清洁取暖等具备用电负荷灵活调整能力的电力用户参与现货市场?通过购入电力富余时段低价电量降低用电成本 。 开展 2023-2025 年周期电网企业输配电价核定。按规定开展辽宁电网输配电准许收入监管 。 积极争取有利资源?落实国家跨省跨区输电价格政策。.做好市场交易与调度运行高效衔接。健全完善电网企业相关业务流程和制度标准?实现电力市场运行与电网调度运行良性互动 。 辽宁电力交易平台实现与电网企业规划、营销、计量、财务、调度等专业平台的数据共享。各级电网调度机构提升电网智能化、自动化水平，加强电力运行调度和安全管理?依法依规落实市场交易出清结果 。. 加强信息共享和披露 。 辽宁电力交易中心按照国家有关规定，与国家、区域及其他省交易中心实现市场主体信息共享 。 落实国家信息披露制度要求，规范披露流程，依法依规披露电网安全约束条件、跨省跨区可用输电能力等关键信息 。 辽宁电力交易中心健全信息安全保障机制，确保电力运行信息安全可控。

（四）二、重点任务[#U0006](https://ecnote.alioc17.cn/doc/LN-LNPX-DISC-2022-119#U0006 "条文锚点 #U0006")

(四)加强电力统筹规划和科学监管. 发挥市场对规划建设的引导作用 。加强电力规划与市场建设之间的衔接，注重发挥市场价格信号对电力规划建设的引导作用。引导煤电、气电等可调节电源合理布局和新能源发电项目有序开发。鼓励新能源发电企业采取共享储能等方式，落实项目并网配套调峰措施。新能源发电配套储能装置、送出工程与新能源发电项目同步规划、同步建设、同步投产，实现源网协调发展。. 完善现代电力市场监管体制。提升对电力市场科学监管能力，加强监测预警?做好预判分析。完善电力调度、交易与市场秩序监管。强化电力交易机构和调度机构的市场运营、市场监控和风险防控职责。加强对电网企业自然垄断性业务的监管，监督检查有关电价和各项辅助服务收费标准。做好对电力市场信息披露情况的监督和评价。. 健全电力市场信用体系。健全市场主体自律和社会监督机制，完善市场主体信用评价制度。开展电力市场交易信用信息系统和信用评价体系建设。对发电企业、供电企业、售电企业和电力用户等不同市场主体，建立信用评价指标体系。推动市场主体信息披露规范化、制度化、程序化，在指定网站按照指定格式定期发布信息，接受社会的监督和政府部门的监管 。. 完善电力应急保供机制。加强省内应急备用和调峰电源投资建设，通过容量成本回收机制、辅助服务市场收益等实现合理经济补偿 。 建立省内市场紧急干预处置机制?优先保障民生用电供应，确保电力供应安全 。

（五）二、重点任务[#U0007](https://ecnote.alioc17.cn/doc/LN-LNPX-DISC-2022-119#U0007 "条文锚点 #U0007")

(五)构建适应新型电力系统的市场机制. 提升电力市场对高比例新能源的适应性 。 建立适应高比例新能源接入的市场机制，推动平价和低价风电、光伏发电量通过参与绿电交易等进入市场，通过绿电交易获得环境价值收益，促进新能源可持续投资 。 提高中长期交易灵活性，适应新能源发电波动性、随机性、间歇性 。 鼓励新能源发电企业与有绿电需求的用户签署较长期限的合同 。 鼓励新能源报量报价参与现货市场?对报价未中标电量不纳入弃风弃光电量考核 。 现货市场运行期间，在现货市场内推动调峰服务 。 随着新能源并网规模不断加大，探索建立爬坡、备用、转动惯量等有功平衡服务市场和自动电压控制、调相运行等无功平衡服务市场 。 探索建立稳定切机、稳定切负荷和黑启动服务等事故应急及恢复服务的补偿机制 。. 建立发电容量成本回收机制 。 建立省内发电容量成本回收机制，探索容量补偿机制、容量市场、稀缺电价等多种方式，保障电源固定成本回收和长期电力供应安全。通过辅助服务市场收益，引导抽水蓄能、电化学储能、物理储能、储热等调节电源投资建设。. 规范开展绿色电力交易。密切关注国家绿色产品认证与标识体系建设和绿色能源消费认证机制建立 。 创新绿电交易机制，探索绿色电力交易与绿证交易、碳排放权交易的有效衔接 。 满足市场主体绿电交易需求，鼓励重点用户带动上下游企业全产业链条参与绿电交易 。 电网企业优先执行绿色电力的直接交易结果 。. 建立分布式发电市场化交易机制 。 健全分布式光伏、分散式风电等主体参与市场交易条件，鼓励与周边用户开展直接交易 。 支持省内增量配电网试点建设 。 完善微电网、存量小电网、增量配电网与大电网间的交易结算、运行调度等机制 。
