# ECNote 政策快照

这批资料是框架早期收录的补充知识库。快照采集于 2026 年 11 月 27 日，包含 2,180 份资料。每份文档的头部保留 ECNote 收录地址及目录字段。资料原有权利由各自权利人保留。项目许可证覆盖框架自身内容。参见[第三方声明](../../NOTICE.md)和[来源站点](https://ecnote.alioc17.cn/)。

发布范围是 `index.json`、`index.csv` 和归一化的 `docs/`。两份文档里合计六个内网失效链接已清除。站点页面、代理留档、登录页面和抓取日志保存在原始归档中。

政策快照随公开仓库部署，可以离线检索。用宿主搜索工具在 `index.csv` 或 `index.json` 按地区、标题和文号筛选，按匹配的 `id` 打开 `docs/<id>.md` 核对正文。已知短语时，对筛出的正文文件搜索相关条款和上下文。

省份、日期、状态取自收录目录。索引中有历史通知、征求意见稿和解读文章，也有空白或未确认字段。需要判断某个交易日的适用规则时，请核对发布机关的原文及修订记录。框架独立核验的官方原文位于 `knowledge/documents/`。
